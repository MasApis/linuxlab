2.3 Memahami Path Absolut vs Relatif di Linux

Di dalam sistem operasi Linux, segala sesuatu direpresentasikan sebagai file dalam struktur pohon hierarkis tunggal. Untuk berinteraksi dan mengelola file secara efektif melalui antarmuka baris perintah (CLI), kamu harus memahami dua cara mendasar dalam menentukan lokasi file atau folder: Path Absolut dan Path Relatif.

info

Kaidah Utama Penulisan Jalur

Ingat: Jalur absolut selalu diawali dengan tanda garis miring (/) yang merepresentasikan root sistem. Jika tidak diawali tanda garis miring, shell Linux akan otomatis menganggapnya sebagai jalur relatif terhadap direktori tempat kamu berada saat ini ($PWD).

1 Navigasi Menggunakan Path Absolut

Path absolut adalah alamat lengkap file atau direktori yang dihitung mulai dari direktori teratas (root /). Keuntungan utama path absolut adalah ia akan selalu berhasil dieksekusi tanpa bergantung pada direktori kerja kamu saat ini.

Terminal — Jalur Absolut
# Berpindah langsung ke direktori log sistem dari mana saja
alex@linuxstart:~$ cd /var/log
alex@linuxstart:/var/log$ pwd
/var/log

2 Navigasi Menggunakan Path Relatif

Path relatif ditentukan berdasarkan posisi direktori kerja kamu saat ini. Jalur ini tidak diawali dengan garis miring /. Linux menyediakan karakter pintas khusus untuk mempermudah navigasi relatif:

. Titik Tunggal
Direktori Saat Ini

Mereferensikan folder tempat shell sedang aktif.

.. Titik Ganda
Direktori Induk (Parent)

Naik satu tingkat ke folder yang menampung direktori ini.

~ Tilde
Home Direktori

Pintasan menuju folder profil pengguna aktif saat ini.

Terminal — Jalur Relatif
# Naik satu tingkat ke induk, lalu masuk ke direktori etc/nginx
alex@linuxstart:/etc/apache2$ cd ../nginx
alex@linuxstart:/etc/nginx$ pwd
/etc/nginx
warning

Jebakan Pemula yang Sering Terjadi

Menulis cd /home vs cd home. Jika kamu sedang berada di /var dan mengetik cd home, Linux akan mencari folder /var/home yang tidak ada, sehingga menghasilkan error: bash: cd: home: No such file or directory.

Referensi sintaks navigasi esensial untuk sesi latihan ini.

pwd Cetak nama direktori kerja aktif ($PWD)
cd / Pindah langsung ke root direktori sistem
cd ~ Kembali ke direktori home pengguna ($HOME)
cd .. Naik satu tingkat ke direktori di atasnya
cd - Kembali ke direktori sebelumnya yang baru dikunjungi
cd /var/log ABSOLUT
Menuju folder log terlepas posisi direktori saat ini
cd ../proyek RELATIF
Masuk ke folder proyek dari posisi folder saudara

Kapan sebaiknya pakai jalur absolut vs relatif dalam skrip bash otomatis?

Saya sedang membuat backup script di crontab. Apakah lebih aman menulis cd backup atau selalu harus cd /home/alex/backup?

verified Jawaban Mentor SysAdmin (Budi Santoso) • Sangat Disarankan

Untuk otomasi seperti cron job atau script system, selalu gunakan path absolut. Karena lingkungan eksekusi crontab biasanya tidak mewarisi $PWD normal pengguna, menggunakan path relatif seringkali berujung pada error direktori tidak ditemukan.
