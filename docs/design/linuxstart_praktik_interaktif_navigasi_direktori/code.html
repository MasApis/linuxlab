Latihan 2.3: Berpindah ke Direktori Sistem & Memeriksa Isi

Pahami cara melintasi hirarki root direktori Linux secara akurat menggunakan perintah dasar sebelum memanipulasi file penting.

flag Tujuan Praktik

Navigasi ke direktori /var/log menggunakan path absolut, lalu periksa berkas log yang ada menggunakan perintah ls -l dan pastikan direktori kerja saat ini adalah /var/log.

Daftar Tugas Praktik 3 dari 3 Selesai
task_alt
Pindah ke direktori /var/log menggunakan path absolut Status: Terverifikasi (cd /var/log)
task_alt
Daftar semua berkas log menggunakan perintah ls atau ls -la Status: Terverifikasi (ls -l)
task_alt
Cetak jalur direktori aktif saat ini dengan perintah pwd Status: Terverifikasi (pwd)
lightbulb Buka Petunjuk (Hint)
expand_more

1. Ingat bahwa path absolut selalu berawal dari tanda slash tunggal / (root direktori).

2. Gunakan perintah pwd (Print Working Directory) setiap saat untuk mengonfirmasi posisi folder kamu saat ini.

keyboard Tips: Tekan Ctrl + L untuk bersihkan terminal
laptop_mac bash — alex@linuxstart: /var/log (Ubuntu 22.04 LTS)
