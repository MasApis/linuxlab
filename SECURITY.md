# 🔒 Kebijakan Keamanan (Security Policy)

LinuxLab menangani lingkungan eksekusi terminal Linux interaktif. Keamanan sistem dan isolasi kontainer adalah prioritas mutlak dalam proyek ini.

---

## 🛡️ Versi yang Didukung

| Versi | Didukung Pembaruan Keamanan |
|:---:|:---:|
| 1.x (v1.1) | :white_check_mark: Ya |
| < 1.0 | :x: Tidak |

---

## 🚨 Melaporkan Kerentanan Keamanan (Vulnerability Disclosure)

Jika Anda menemukan potensi celah keamanan (misalnya: *container escape*, *privilege escalation*, kebocoran Docker socket, atau *bypassing* penilaian):

1. **JANGAN membuat issue publik di GitHub** untuk masalah keamanan yang kritis.
2. Silakan laporkan secara privat melalui fitur **GitHub Private Vulnerability Reporting** di tab *Security* repositori ini, atau kirimkan email ke pengelola proyek.
3. Sertakan rincian:
   - Deskripsi potensi dampak celah keamanan.
   - Langkah-langkah pembuktian konsep (*Proof of Concept / PoC*).
   - Saran perbaikan (jika ada).

Tim pengelola akan meninjau laporan, memverifikasi masalah, dan merilis patch perbaikan secepat mungkin.
